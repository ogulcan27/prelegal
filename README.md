## Getting Started

### Prerequisites

- Node.js 22.12+, 24 or 26 (required by Vitest; the app itself needs Node.js 20.9+)
- npm

### Installation

```bash
git clone https://github.com/ogulcan27/prelegal.git
cd prelegal/frontend
npm install
```

## Usage

### Mutual NDA creator

The `frontend/` directory contains a Next.js app for creating a Common Paper Mutual Non-Disclosure Agreement. Fill in the form, watch the agreement update in the live preview, and download the completed agreement as a PDF.

Run these from `frontend/`:

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the development server at http://localhost:3000 |
| `npm run build` | Creates a production build |
| `npm start` | Serves the production build |
| `npm test` | Runs the unit tests (Vitest) |
| `npm run lint` | Runs ESLint |

The app reads the agreement text from `templates/Mutual-NDA.md` and `templates/Mutual-NDA-coverpage.md` at build time. Build it from a full checkout of this repository: a build that only has the `frontend/` directory (for example, a deployment with `frontend/` set as the root directory) fails because the templates are missing.

### Templates

`templates/` contains the Common Paper standard agreements, listed in `catalog.json`. They are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see `templates/LICENSE.txt`. Documents generated by the app keep the Common Paper attribution.
